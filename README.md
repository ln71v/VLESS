# VLESS + Reality: сервер, Telegram-бот и роутер Keenetic

Свой VPN на протоколе VLESS + Reality без веб-панели. Трафик выглядит как обычный HTTPS к крупному сайту, поэтому его сложно заблокировать, в отличие от WireGuard и AmneziaWG.

- **`vless.sh`** — установка и управление на сервере через меню в терминале.
- **Telegram-бот** — выдаёт и удаляет ключи кнопками, присылает QR-код.
- **`router/vless-router.sh`** — Xray на роутере Keenetic, чтобы через VPN шёл весь дом.

## Что нужно

- **VPS** за границей: Ubuntu 22.04 или 24.04, от 1 ядра и 512 МБ памяти, белый IPv4, доступ root по SSH.
- **Приложение** хотя бы на одно устройство:

  | Устройство | Приложения |
  |---|---|
  | Android | Hiddify, v2rayNG, Happ |
  | iPhone | Happ, Streisand, v2RayTun |
  | Windows | Hiddify, v2rayN |
  | macOS | Hiddify, Happ |

- **Для бота** (по желанию): токен от [@BotFather](https://t.me/BotFather) (`/newbot`) и свой Telegram ID от [@userinfobot](https://t.me/userinfobot).
- **Для роутера** (по желанию): Keenetic с Entware на USB-флешке.

## 1. Сервер

Зайди на VPS по SSH под root и выполни:

```
bash <(curl -Ls https://raw.githubusercontent.com/ln71v/VLESS/main/vless.sh)
```

Откроется меню:

```
══════ VLESS + Reality ══════
  1) Установить Xray (VLESS + Reality)
  2) Показать ключ пользователя (QR + ссылка)
  3) Добавить пользователя
  4) Удалить пользователя
  5) Установить Telegram-бота
  6) Статус
  7) Обновить Xray и бота
  8) Удаление
  0) Выход
```

Выбери **1**. Скрипт спросит:
- **порт** — по умолчанию 443; если он занят (например, nginx), предложит 2083;
- **сайт для маскировки** — по умолчанию `www.yahoo.com`;
- **название сервера** — так ключи будут подписаны в приложении;
- **имя первого пользователя**.

В конце покажет QR-код и ссылку `vless://...`: отсканируй QR в приложении, и готово. Если на сервере включён файрвол `ufw`, порт откроется сам.

Меню можно запускать повторно той же командой: добавлять и удалять пользователей, смотреть их ключи.

## 2. Telegram-бот

В меню сервера выбери **5**, введи токен бота и свой ID. Скрипт проверит токен, скачает бота и запустит его.

В Telegram открой своего бота и нажми `/start`. Внизу появятся кнопки:
- **➕ Добавить** → бот спросит имя → пришлёт QR и ссылку;
- **👥 Пользователи** → список → у каждого **🔑 Ключ** и **🗑 Удалить**.

Бот отвечает только тебе (по ID), остальным молчит. При добавлении и удалении Xray перезапускается, у всех на секунду рвётся связь.

## 3. Роутер Keenetic

Xray на роутере поднимает для каждого сервера локальный прокси, а Keenetic видит его как обычное подключение. Дальше в «Маршрутизации» ты сам решаешь, какие сайты куда отправлять, как с WireGuard.

**Подготовка в Keenetic:** Общие настройки → Изменить набор компонентов → должны стоять «Поддержка открытых пакетов (OPKG)» и «Клиент прокси». Entware установлен на флешку.

Зайди в Entware по SSH (порт 222, если стоит штатный SSH-сервер Keenetic, иначе 22) и выполни:

```
curl -fsSL https://raw.githubusercontent.com/ln71v/VLESS/main/router/vless-router.sh -o /opt/bin/vless-router && chmod +x /opt/bin/vless-router && vless-router
```

В меню:
1. **Установить Xray на роутер.**
2. **Добавить сервер:** вставь ссылку `vless://` (из бота, приложения или 3x-ui), дай имя. Скрипт назначит порт (1080, 1081, …) и проверит связь.

Потом в веб-интерфейсе Keenetic для каждого сервера:
1. Интернет → Другие подключения → **Прокси-подключения** → Добавить:
   - Тип: **SOCKS5**
   - Адрес: `127.0.0.1:1080` (порт из скрипта)
   - Аутентификация: не использовать
   - Галка **«Использовать для выхода в интернет»**
2. **Приоритеты подключений** → поставь это подключение **ниже** основного провайдера, иначе в VPN уйдёт весь интернет.
3. **Маршрутизация** → в нужных списках доменов выбери это подключение. Если его нет в списке, обнови страницу (Ctrl+F5).

Повторный запуск меню: `vless-router`.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| Приложение не подключается, тайм-аут | Проверь, открыт ли порт у хостера и в `ufw`: `ufw allow ПОРТ/tcp` |
| Порт 443 занят | При установке выбери другой, например 2083 |
| Провайдер режет конкретный сайт маскировки | Переустанови (пункт 1) с другим сайтом: `www.yahoo.com`, `www.apple.com`. Не бери google.com |
| YouTube в браузере не грузится, остальное работает | Отключи QUIC: `chrome://flags/#enable-quic` → Disabled |
| При вставке в терминал появляется `^[[200~` | Termius портит длинные вставки. Запускай скрипт командой выше, ничего длинного вставлять не нужно |
| Бот молчит | На сервере: `journalctl -u vless-bot -n 30 --no-pager` |

## Где что лежит

| Сервер | |
|---|---|
| `/usr/local/etc/xray/config.json` | конфиг Xray, все пользователи |
| `/usr/local/etc/xray/vless-meta.env` | название и IP сервера |
| `/opt/vless-bot/bot.py`, `/etc/vless-bot.env` | бот и его настройки (токен) |

| Роутер | |
|---|---|
| `/opt/etc/xray/servers.list` | список серверов: порт, имя, ссылка |
| `/opt/etc/xray/config.json` | собирается автоматически из списка |
| `/opt/etc/init.d/S24xray` | автозапуск |
